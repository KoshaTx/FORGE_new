% FORGE reachable-space figure, pure TikZ.
%
% Rebuilt from an SVG-plus-overlay version: hand-fitted organic blobs read as lumpy rather than
% considered, and the overlay forced Computer Modern maths beside a Helvetica sans, which clashed.
% Clean nested ellipses state a set relationship more clearly, and drawing in TikZ means every label
% and every symbol is the document's own font with no overlay coordinates to keep in sync.
%
