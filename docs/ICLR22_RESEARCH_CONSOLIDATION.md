# ICLR22 research consolidation

The five development streams are consolidated without changing the default generation or
selection policy. Source and compact audit records are tracked; the manuscript, unrelated
training changes, large arrays, model checkpoints and planner assets are outside this change.
All 91 original worktree additions remain byte-preserved in the consolidation archive. Of
these, 49 have maintained main-checkout counterparts and 42 remain historical producers.

Current development evidence covers all 1,408 requests, 64 per family: exact L1 is 1,387,
limited design passes are 1,331, computational makeability is 624, L2-ready is 1,189,
direct-listed L3 is 121, and strict dossiers are 27. These are one-fit TRAIN-derived
results. Independent held-out/multi-fit evidence and broader empirical realism remain open.
The trained-null fit has no admitted quality result; the corrected paid retry is unsubmitted.

The summary, full family denominators, negative interventions and input hashes are in
[`results/phase1/compose_lipid_iclr22_parallel_improvement_v1/`](../results/phase1/compose_lipid_iclr22_parallel_improvement_v1/README.md).
Its `consolidation_v1/` records source dispositions and original/destination hashes.
The `commit_push_v1/` receipts distinguish isolated-source checks from original-workspace
integration checks. Historic receipts describe the exact files and workspace at their
recorded time; their hashes must not be rewritten to describe a later Git commit.

## Source and artifact requirements

Some existing evaluators import versioned helper modules from `results/phase1/`. The
required Python dependency closure is included explicitly, preserving the frozen sources.
The computational-makeability classifier/policy and retained-head/topology checks are
included with their owning tests. Existing strict dossier acceptance is unchanged.

Git is not the complete experiment artifact bundle. Saved-structure tests and scientific
replays additionally need the authenticated TRAIN cache, qualified chemistry registries,
head-policy fixture, saved candidate/route ledgers and original source-bound admissions.
The route integration tests also authenticate original producer paths, planner assets and
filesystem attestations. Copying or symlinking those inputs into a different checkout does
not establish a new admission. Preserve the originals; qualify any relocation separately.
Do not rewrite pins, relax the real-file checks, rerun one-shot producers over existing
outputs or treat missing evidence as a scientific negative.

The portable source check runs all selected owning tests except
`experiments/phase1/route_improvement/test_candidate_routes.py` and
`tests/test_new_clock_routes.py`, which exercise the historical route bundle. Remaining
saved-head and topology fixtures still require their hash-pinned non-code inputs. The full
original-workspace check includes both route files and has 196 cases. Exact commands,
input/source hashes, the initial temporary-link refusals and final receipts accompany the
commit audit. No model training, route search, network chemistry lookup or final TEST
access is part of this validation.

The source-selection manifest explicitly excludes unrelated working-tree changes. To
reproduce these checks, use the recorded base plus selected source hashes and the declared
artifact bundle; an editable installation pointing at another checkout is insufficient.
