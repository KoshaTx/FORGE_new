## Outcome

The LNPDB route-curation surface is finite and tractable. The immutable raw export contains 19,797
row-level records and 12,837 unique canonical ionizable lipids. Its `LNP_ID` set and canonical
structure set match the LNPDB subset of R0 exactly.

This matters because R0 aggregates provenance by canonical structure. A merged R0 record can preserve
sets of PMIDs, experiment identifiers, names, and source records without preserving the original
pairing between those fields. The raw export restores exact row-level relationships and is therefore
the authoritative input for paper-to-component curation.

## Provenance defect caught

LNPDB rows for experiment `SB_2024` report PMID `29786478`, but their publication link is
`10.1016/j.bioactmat.2024.05.012`. The reported PMID resolves to an unrelated stroke consensus
statement. The row DOI resolves in PubMed to PMID `38779592`, *A lipid nanoparticle platform
incorporating trehalose glycolipid for exceptional mRNA vaccine safety*.

The ledger records both the reported and resolved identifiers, the reason for correction, and the
primary evidence URL. It does not silently replace the source field.

## Evidence contract

A component progresses through separate route and procurement states.

Route evidence:

1. `not_assessed`
2. `source_identified`
3. `route_extracted`
4. `forward_verified`
5. `internally_validated`

Procurement evidence:

1. `not_assessed`
2. `vendor_claim_only`
3. `vendor_verified`
4. `internal_stock_verified`

A component is executable only if it is procurement-verified, or if it has a forward-verified route
whose leaves are procurement-verified or internally stocked. A whole lipid is executable only when
L1 assembly closes and every L2 component closes under this recursive rule.

Publication linkage, structural plausibility, and presumed commercial availability are insufficient.

## Evidence-bounded source priority

`make m0-09-source-priority` adds a deterministic priority overlay without
changing the original acquisition queue. It combines six equal-weight axes:

1. motif distinctiveness, using only exactly mapped classes in the curated
   cross-platform transfer ledger;
2. biological provenance, using the presence and depth of source-linked LNPDB
   measurements without comparing assay magnitudes;
3. exact component-identity novelty relative to the frozen AGILE component
   universe;
4. source-method accessibility, including hash-pinned or publicly accessible
   source packages and completed visual review;
5. Ugi-handle conversion evidence, limited to native Ugi component routes or
   explicitly forward-verified transfers;
6. exact component redundancy across LNPDB source families.

The overlay contains the same 43 source rows as the acquisition queue: 42
publications and one commercial source. Four completed chemistry reviews remain
in the evidence-value ranking but receive no `next_review_rank`. The remaining
39 sources form the active queue. Existing evidence covers all 43 sources for
biological provenance, exact AGILE novelty, method accessibility and exact
component redundancy. Explicit motif-transfer evidence exists for two sources,
and Ugi conversion evidence exists for five. Therefore, 41 sources retain at
least one missing priority axis.

Missing evidence receives zero credit and is written to
`missing_priority_axes_json`. It is never interpreted as favorable. The first
two active sources are PMID 39497197 and PMID 40060499 because their source
reactions, mapped motifs and proposed Ugi realizations were already curated.
The next two are PMID 39502027 and PMID 38409275; both still have explicit
missing motif and Ugi-conversion evidence.

The score prioritizes evidence review. It is not a biological-potency,
synthesis-success, route-closure or procurement score. Biological provenance
does not transfer a source lipid's assay label to a motif, component or
generated Ugi product. Exact structural novelty does not establish Ugi
compatibility or biological value.

## How recovery will be reported

The previous M0-04 percentages remain structural diagnostics. They answer whether a held-out completed
lipid can be reconstructed exactly from train-derived completed components. They do not measure
synthesizability.

The route-aware report will separate:

1. exact whole-structure recovery;
2. L1 assembly closure;
3. source-linked L2 component coverage;
4. extracted complete-route coverage;
5. forward-verified L2 route coverage;
6. L3 procurement closure;
7. whole-lipid executable coverage.

Only the last quantity supports a complete synthesis-dossier claim.
