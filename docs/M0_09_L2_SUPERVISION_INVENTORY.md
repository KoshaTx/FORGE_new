## Finding

A standalone learned lipid-specific L2 route model is **not supported by the available corpus**. Retain
generic reaction pretraining, but use it inside a hybrid architecture: **generic neural proposal plus
deterministic, source-linked lipid template search**.

The limiting evidence is not final-lipid structure count. It is observed upstream reactions with
outcomes: the reviewed lipid-specific sources contain 55 reaction instances, 32 terminal precursor
scaffolds, no explicit failed syntheses, and no carbonate or heterocycle-forming lipid examples.

For the current paper, the relevant core is narrower: AGILE reports 18 aldehyde-tail routes and seven
isocyanide-tail routes for its amine–aldehyde–isocyanide Ugi 3-CR assembly. The aldehyde set is
moderately diverse, while the isocyanide set is the clear coverage bottleneck. See
`docs/M0_09_UGI3_PRECURSOR_CAPABILITY.md`.

USPTO-MIT has 409,035 train, 30,000 validation, and 40,000 test records. USPTO-50K contains 22,773
distinct source-document IDs; an ID can contribute multiple reactions. The distributions are retained
separately so the class-labeled benchmark is not misreported as the large pretraining corpus.

### Lipid-relevant screening coverage

Counts below are candidate formation reactions. For ester, isocyanide, aldehyde, carbonate, and
acrylate, a candidate has the product motif and no reactant molecule with that motif. This is a
screening heuristic and an upper bound, not route validation. USPTO-50K heterocycle coverage is its
class-4 count; USPTO-MIT does not have the labels needed for the same count.

The generic corpus is therefore worth retaining, especially for ester and aldehyde chemistry. It does
not replace lipid-specific validation, and its isocyanide support is thin relative to corpus size.

## Structure corpora: useful, but not route labels

R0 contains 15,433 measured real lipids and already preserves useful region annotations:

| LNPDB head SMILES | 10,103 | 432 |
| LNPDB linker SMILES | 2,835 | 36 |
| LNPDB Tail-1 SMILES | 9,602 | 248 |
| LNPDB Tail-2 SMILES | 2,451 | 45 |
| LiON explicit amine SMILES | 1,158 | 239 |
| AGILE measured A / B / C components | 1,200 | 20 / 12 / 5 |

The AGILE Zenodo candidate file adds 12,276 unique unlabeled final-lipid structures. These corpora can
support representation learning, real-lipid coverage analysis, and head/tail prioritization. They do
not state how a block was made or whether an attempted synthesis failed.

For the non-circular R1′ rebuild, split R0 first, harvest blocks from `R0_train` only, retain source and
occurrence provenance, validate required handles, and audit decomposition precision before using a
block. The existing 464,265-member R1 remains a weighted auxiliary product corpus; it is not L2
supervision and not route-certified.

## Decision and action plan

1. Pretrain reaction proposals on USPTO-MIT; use USPTO-50K for class-aware benchmarking and holdouts.
2. Encode the four observed Ugi-3 precursor transformations, esterification, alcohol oxidation, amine
   formylation, and formamide dehydration, as deterministic, source-linked templates.
3. Use train-only R0/LNPDB/LiON head, linker, and tail annotations to prioritize template coverage and
   the R1′ block pool, not to invent route labels.
4. Prioritize new Ugi-compatible isocyanide and aldehyde routes, including branching, degradable
   linkages, spacer variation, yields, and failed attempts.
5. Record every future internal attempt with substrate, conditions, conversion or yield, analytical
   evidence, and an explicit success/failure status.
