# Continuous activity-conditioned FORGE

Status: revised research protocol, not an executed training result. Revision 2, 2026-09-25.
The user requires continuous measured activity as the primary target and rigorous evidence
for an ICLR contribution. The previous class-conditioned proposal is archived at
`results/phase1/potency_guidance_hypotheses_v2/activity_conditioned_proposal_v1.md`.

## Research question

Can continuous measured activity improve reaction-constrained whole-lipid generation beyond
structural domain adaptation and post-hoc ranking, in a supported biological context and
under declared resource budgets?

Reuse the 22-family checkpoint. Continuous conditioning and predictor-free guidance are
existing methods, so adding them alone is not a novelty claim. A contribution requires
showing what they add to reaction-constrained generation, where generalization holds,
and which mechanism produces any measured computational improvement.

## Measurement contract

A labeled record is `(G, P, c, s, y)`: constitution, qualified reaction program, assembly
chemistry, assay context and observed continuous response. Context retains cell, study,
cargo, formulation, dose, time, readout and normalization where known. Missing metadata
remains missing. The existing expanded corpus retains source-normalized responses in
separate study/context tasks; it does not establish a common raw transfection-efficiency
scale. Audit exactly how each source defines mTP before calling its values comparable.

Preserve continuous source values, units and available raw measurements. Numerical
conditioning may use `z = T_s(y; eta_s,fit)`, with preprocessing fixed before evaluation
and parameters estimated from fitting data only. Affine standardization preserves the
source information. Use a log transformation only if justified by endpoint semantics and
support; do not invent offsets for zeros or negative normalized values. Retain the inverse
transform when defined. Numerical scaling does not make different assays biologically
commensurate, and train-only scaling cannot undo normalization already performed across
an entire source library.

The primary training target has no low/medium/high bins or percentile replacement.
Quantiles may select continuous evaluation target points and define secondary enrichment
metrics. Preserve censoring, replicate provenance and repeated formulations explicitly.
Do not turn censored measurements into invented point labels or count changed formulations
as independent lipid designs.

Resolve the 115/550 HeLa tail2 annotation disagreements with exact replay before admitting
biological reaction annotations. Keep supplied source materials distinct from immediate
assembly precursors. A correction requires a versioned, independently checked rebuild;
the historical baseline remains unchanged. This discrepancy does not establish that the
molecule/activity pairing is wrong.

## Conditional model and objective

The proposed factorization is

    p(G, P | c, s, z) = p_phi(P | c, s, z) p_theta(G | P, s, z).

Both factors matter. FORGE chooses a program before denoising; that program fixes active
positions and coarse architecture, including role-specific size and branching information.
Conditioning only the denoiser leaves this architectural distribution unchanged. It may
therefore restrict activity control. This is an architectural inference to test, not an
established explanation for earlier failures.

Embed the continuous scalar with a learned smooth scalar embedding and add activity/context
conditioning to the existing denoiser. Train on corrupted measured molecules using

    L_activity = E[sum_i w_i(P) * -log d_theta,i(X_star,i | X_t,t,P,s,z_tilde)],

where `z_tilde` is the continuous measured condition or a deliberately dropped condition.
The reconstruction target is the observed molecule. The numerical activity is a condition,
not a categorical molecular coordinate. Cover the inference-time corruption schedule;
train or separately qualify the terminal readout. Preserve fixed states and allowed masks.
Compare limited backbone adaptation and adapters as capacity controls.

For label dropout, hide activity while retaining the same reaction and assay context on
the same measured examples. Mix this loss with chemistry training on original TRAIN-only
replay records, using explicit mixture weights. Unlabeled records have missing biological
conditions, never fabricated zero activity. Preserve molecular-size support. Activity
supervision comes from measurements rather than predictions generated by the current head.

Fit a regularized conditional prior over admissible programs, retaining the existing prior
as a control. Specify support, smoothing and sparse-context behavior before execution.
Evaluate program-only, denoiser-only and joint conditioning separately. Sampled programs
supply no new chemistry evidence or biological measurements.

## Discrete guidance

Start with ordinary continuous-conditional sampling. A separate intervention uses
predictor-free CTMC rate guidance. On permitted transitions with positive rates:

    R_gamma = R_conditional^gamma * R_context_only^(1-gamma).

Gamma=0 gives the activity-dropped branch and gamma=1 ordinary conditional generation.
Both retain the same program/context. Forbidden and fixed-coordinate transitions stay
zero; diagonal entries are negative row sums. Define zero-rate handling and check boundary
identities before running guidance. Mixing endpoint logits is a different approximation
unless equivalence for this sampler is demonstrated. Finite learned rates, capped updates
and terminal readout do not inherit an exact globally tempered terminal-law guarantee.

This rate construction is prior work
([Nisonoff et al., Eq. 3](https://proceedings.iclr.cc/paper_files/paper/2025/file/597254dc45be8c166d3ccf0ba2d56325-Paper-Conference.pdf)).
Conditional/label-dropped training follows
[Ho and Salimans](https://arxiv.org/abs/2207.12598).
These references establish methodological precedent, not lipid-transfection efficacy.

## Discriminating comparisons

Use identical initialization, admitted records, optimization budgets and selection rules:

1. Frozen generator plus post-hoc ranking.
2. Structural adaptation with activity hidden.
3. Continuous-activity denoiser conditioning with the original program prior.
4. Activity-conditioned program prior with activity hidden from the denoiser.
5. Joint continuous conditioning of both factors.
6. An identical conditional arm with labels shuffled within comparable assay contexts.

A binned-target control may test information loss; it is not the primary model. Tune guidance
strength separately so it does not confound these comparisons. Select replay fractions,
capacity and stopping rules on development data. Pair seeds and requested contexts.
Report proposal counts, denoiser evaluations, scorer calls and runtime separately. Two-branch
guidance uses extra evaluations; matching attempts alone is not matching compute.

## Evaluation and allowable conclusions

Keep protected identities and reservations closed. Group molecular identities, source
components, close structural neighborhoods and repeated formulations as appropriate to
the question. Report within-library, held-component and held-study results separately.
Audit unlabeled pretraining exposure: held activity labels do not imply unseen structures.
The admitted HeLa/A549 libraries have no cross-cell identity bridge. Cell/study association
can be modeled, but a disentangled causal cell effect is not established. A549 is not a
general lung-delivery endpoint.

On held measured molecules, test conditional denoising across times and continuous activity
values against hidden and shuffled conditions. Denoising loss is not automatically a
molecular log likelihood. A reduction shows use of the condition, not generated-lipid
activity. If an auxiliary activity predictor is added, its inputs must exclude the activity
label it is supposed to predict.

For generated molecules, use a prespecified continuous target grid within supported ranges.
Report target control, validity, exact assembly, uniqueness, diversity, training duplication
and predictor applicability with all attempts retained. Test whether any predicted shift
survives the structural-adaptation, program-prior and shuffled-label controls. Use independent
training seeds and biological/structural groups for uncertainty; generated molecules are
not experimental replicates. Report failure and abstention denominators.

Select evaluation predictors independently of generation tuning and qualify their domain.
Independence alone does not validate an out-of-domain evaluator. Higher independently
predicted activity remains a computational outcome. Optimizing and evaluating the same
predictor is insufficient evidence. Biological claims about new lipids require independent
measured evidence; obtaining it is outside this proposal's execution scope.

Before execution, freeze numerical decision margins and resource/power assumptions after
the corrected data census and implementation preflight. Do not set success thresholds after
seeing results. Existing repeatedly exposed development folds cannot supply confirmation.
A positive result must distinguish use of genuine activity information from library
adaptation, memorization and evaluator artifacts. No publication outcome is guaranteed.

Evidence ledger: target semantics, annotation discrepancies and prior parallel results are
local-source/computed findings. CTMC guidance is reported prior work. The program-prior
bottleneck is an architectural inference. All training changes and claimed future benefits
in this document are proposed and unexecuted.
