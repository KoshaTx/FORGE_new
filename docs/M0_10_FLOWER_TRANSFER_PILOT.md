# M0-10 FlowER transfer pilot

## Outcome

The scientifically valid FlowER transfer pilot is blocked and was not run.
FlowER is therefore demoted mechanically to an orthogonal consistency check.
The deterministic atom-mapped forward verifier remains load-bearing.

This result does not block whole-lipid product-model training or the hybrid L2
route system.

## Asset audit

The local FORGE workspace does not contain a hash-pinned FlowER source checkout
or the pretrained `model.2880000_95.pt` checkpoint. The May 2026 probe scripts
downloaded the public code and Figshare archives into a transient Modal image.
The prior memo and scripts are present locally and are hash-pinned by the
M0-10 artifact, but they are prior evidence rather than a replacement for the
frozen transfer experiment.

## Supervision audit

The three frozen pilot classes are:

- aza-Michael addition of an amine to an acrylate;
- amine opening of an epoxide;
- reductive amination.

Each registry entry has one atom-mapped positive qualification example and one
negative handle or applicability example. None has a FlowER elementary
bond-electron trajectory. The 32-example-per-class curve therefore has a
deficit of 32 mechanism trajectories for every class.

The current precursor capability ledger contains 82 string-valued prospective
outcomes, all marked `not_attempted`. It contains no measured prospective
conversion outcomes. Literature yield and deterministic transform validity are
not substituted for prospective conversion.

## Frozen demotion rule

FlowER may remain in the headline mechanism only if:

1. fine-tuning improves held-out forward consistency; and
2. its score correlates with prospective conversion with a Spearman confidence
   interval excluding zero.

Neither condition can currently be evaluated. FlowER is not authorized as a
mechanism-grounded claim, route planner, synthesis value, or load-bearing
verifier.

## Next authorized acquisition step

1. Vendor an exact FlowER commit and the Figshare version 3 checkpoint with
   license, SHA-256, and archive-member provenance.
2. Curate and freeze at least 32 elementary mechanism trajectories for each
   target class, with a reaction-class holdout fixed before fine-tuning.
3. Run the frozen 0, 8, 16, and 32 example curve and report exact forward
   trajectory accuracy, a reliability table, expected calibration error, Brier
   score, and substrate-family bootstrap intervals.
4. Evaluate the prospective-conversion condition only after a locked synthesis
   ledger contains measured conversion for every attempted candidate.

No automatic download or compute run is authorized by this blocker report.
