# Five-worktree improvement campaign

This campaign executes the user's accepted parallel research prompt. The manuscript is unchanged.
All five worktrees began from the same 2,686-file snapshot, including the existing uncommitted
source. `baseline/source_manifest.json` pins that snapshot; its source digest is
`497bf6b57586f25a76d8380cda7d272dc83be73ed74130dca0f3eb30b20597e0`.
`baseline/result.json` freezes the complete 1,408-request, 22-family development baseline.
The current readable per-family counts are in [FAMILY_METRICS.md](FAMILY_METRICS.md).
The five-stream source consolidation is documented in [consolidation_v1/README.md](consolidation_v1/README.md).

The initial priorities are useful learned contribution, weak-family structural quality,
independent evaluation, recursive route closure, and component concentration. Each stream has
its own worktree, input pins, bounded experiment and failure records. The three worker slots
run A, B then E, and D; the coordinator owns C, independent admissions and consolidation.
Shared data/results are immutable inputs except each stream's explicitly owned output directory.
Paid execution is serialized, detached and independently reviewed; local work continues alongside it.

The streams' gains cannot simply be added. The first independently reassessed B+D candidate
cohort had 620 computationally makeable products and 1,177 L2-ready products, compared with 621
and 1,189 for D alone. The subsequent exact-head recovery and disulfide evidence bring B+D to
622 makeable and 1,178 L2-ready, while the original D population reaches 622 and 1,189.
No changed molecular identity inherits old L2/L3 or strict dossier verdicts. Likewise,
per-family diversity floors do not guarantee pooled diversity floors: E's
ordinal control fails a pooled floor and is not eligible for promotion.

The dominant cyclic-family isocyanide is a coverage problem: all 35,728 TRAIN graphs contain the
same Iso6 variant, while the registry admits Iso4, Iso5 and Iso6. All 64 current requests have
six fixed core nodes and four variable exterior nodes. A fixed-pool selector cannot create the
missing component-size support. The original concentration metric remains unchanged.

The complete A3/ketone-Ugi4 census scans 34,104 and 27,027 authenticated TRAIN graphs.
All 128 requests, including all 33 current limited-design failures, have at least one
whole-component witness for every role satisfying the declared core, quantity, size,
morphology and ring conditions. This is necessary support, not proof that mixed components
assemble or that the resulting lipids are realistic. Only five current A3 heads and no
current ketone-Ugi4 ketone components match those whole TRAIN identities. All 62 exact
ketone-Ugi4 ketone components are TRAIN-novel, so replacing them with known components
would violate the unchanged novelty floor. The next intervention must improve novel whole
components and recheck assembly, quality, diversity and routes together. Census and independent
verification are in `b_quality/component_feasibility_v1/run_v2/`.
Because the layouts are TRAIN-derived, this rules out empty necessary support for the
sampled requests; it does not independently establish decoder causation or source-disjoint
generalization.

Comparison and promotion rules:

- Retain all requests, candidates, invalid outputs, abstentions, censored searches and negative
  experiments. Selected L1 is a final-system metric; raw yield is a separate stage diagnostic.
- Freeze candidate pools and budgets for selection controls. Attribute extra proposal work and
  selection separately from learning. A count-only unconditional null and a semantic-null model
  supplied common structural context answer different questions and must be named separately.
- Assess quality, concentration/novelty and route evidence on the same exact selected identities.
  Require per-family and pooled checks before replacing the current selection.
- Use the unchanged structural policy with only identity-authenticated tree-basis evidence.
  The old all-candidate census gave 1,312 design passes for the selected panel; the common current
  ledger authenticates 15 exact tree transports and reproduces 1,324. Do not mix those snapshots.
- TRAIN support and synthetic-CAL neighborhoods are support/distribution diagnostics. They do
  not establish independent empirical lipid realism. Preserve the six families without qualified
  unseen-component CAL examples as missing coverage.
- Freeze the complete system, fit seeds, test population, matched controls, budgets and uncertainty
  analysis before final TEST access. Independent generation seeds do not replace independent fits.
